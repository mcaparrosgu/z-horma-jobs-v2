# Horma jobs

Metabuscador europeo de empleo (de momento, España) con entrevista de perfil, CV y carta honestos orientados a ATS, agente de candidatura, seguimiento y portal de empresas. Proyecto final del bootcamp de AI Engineering de Neoland.

- **Pista A** (`.claude/`): agentes, skills y comandos de Claude Code. Tests: `python -I evals/correr_evals.py`.
- **Pista B** (`web/`): Next.js + PostgreSQL, sin LLM dentro. Ver `web/README.md`.
- Diseño: `docs/flujo-agentico.md`. Estado: `docs/estado.md`.
